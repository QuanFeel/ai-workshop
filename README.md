# AI Workshop

面向 AI 使用者和 Agent 开发者的开源实验仓库。每个目录都是一个可以独立阅读或使用的小项目。

## 项目目录

| 目录 | 内容 | 使用方式 |
| --- | --- | --- |
| [`3D-memory-courtyard/`](./3D-memory-courtyard/) | 用 AI 生成“记忆小院”3D 互动相册的完整提示词 | 阅读并复制 `prompt.md` |
| [`feishu-skill-hub/`](./feishu-skill-hub/) | 用飞书知识库集中发布、拉取和更新 Agent Skills | 安装 `feishu-cli` 与 `feishu-skill-sync` |

## 使用原则

- 每个项目的依赖、安装、验证和安全边界，以该目录中的 README 为准。
- 不要把 Token、App Secret、OAuth 临时代码、个人配置或本机缓存提交到仓库。
- 涉及外部平台写入的工具，必须先展示真实账号、目标位置和写入计划，再由用户确认。
