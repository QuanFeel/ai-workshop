# 安全说明

## 报告安全问题

不要在公开 Issue 中粘贴 App Secret、Token、`device_code`、Open ID、Tenant Key、知识库 Token、Profile 配置或包含这些信息的完整日志。

请优先通过 GitHub 仓库的 Security 页面提交私密漏洞报告，只提供复现问题所需的最小信息，并先对账号、资源标识和日志做脱敏。如该入口暂未开放，只创建不含敏感信息的 Issue，请求维护者提供私密联系渠道。

如果真实凭据已经公开，请立即在飞书开放平台或官方 CLI 中撤销对应授权、轮换凭据，并删除本机受影响的 Profile 或缓存；仅删除 Git 中的文件不能使已泄露凭据失效。

## 安全模型

- 本仓库不保存 OAuth Token 或 App Secret，凭据由官方 `lark-cli` 管理。
- `feishu-skill-sync` 只缓存知识库位置和身份指纹，不缓存登录凭据。
- 远端发布和本地安装前都需要版本计划与人工确认。
- 下载 ZIP 在安装前校验路径、顶层目录、Skill 名称和版本。
- CLI 失败信息会省略原始输出并脱敏结构化敏感字段。

## 不在支持范围内

- 用户主动把凭据写入 Skill、脚本、环境文件或公开日志。
- 绕过同步脚本，直接拼接 `lark-cli` 写入命令。
- 修改代码后关闭确认、版本门禁或 ZIP 校验。
- 第三方 Agent、飞书客户端或官方 `lark-cli` 自身的漏洞。
